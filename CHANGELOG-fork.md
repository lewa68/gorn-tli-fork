# Изменения форка

Человекочитаемый список того, что форк добавляет к официальной версии.
Заметки релизов собираются из этого файла: секция «## <версия>» — новое
в этой сборке.

## 1.0.32-fork.18

- Память тюрьмы перечитывается с нуля, как только перестаёт сходиться с
  экраном («нет дверей», «нет едока», ходы движка не видны) — вместо
  молчания или советов о том, чего на экране нет
- Кнопка «Перечитать тюрьму с нуля» в настройках и хоткей Ctrl+Alt+R:
  вручную забыть всё, что запомнено о текущем забеге

## 1.0.32-fork.17

- Обычная доска без карточек больше не принимается за экран решения: на
  английском клиенте она ложно читалась как «Выберите цель», из-за чего
  трекер мог советовать «Остановить цепочку», когда никакой цепочки нет
- Текст доски больше не притворяется подписями карточек (по высоте знаков)

## 1.0.32-fork.16

- Английский клиент, экран выбора двери: номер на карточке читается, вокруг
  нужной двери рисуется рамка (порог высоты букв при чтении цифр подогнан
  под английский шрифт)
- Английский клиент, меню конца дня (съесть / заменить / закончить):
  карточки узнаются по иконкам, вокруг нужного действия рисуется рамка —
  раньше экран молчал

## 1.0.32-fork.15

- Экран выбора орудий больше не бракуется на английском клиенте: карта
  узнаётся по картинке орудия, даже если надпись не совпала с эталоном
  (эталоны надписей собраны с русского клиента)

## 1.0.32-fork.14

- Исправлена ошибка сборки, из-за которой форки fork.12 и fork.13 выходили
  без интерфейса: приложение открывалось чёрным окном. Установка fork.14
  восстанавливает нормальный запуск
- Пайплайн сборки теперь не проходит молча: если интерфейс не собрался,
  релиз не публикуется вовсе

## 1.0.32-fork.10

- Оверлей исчезает сразу, как игра сворачивается или закрывается — больше
  не висит над рабочим столом
- Наблюдатель фокуса больше не опрашивает список процессов каждые 400 мс —
  постоянная нагрузка на процессор снизилась почти до нуля
- Наличие игры определяется по её логу: пока игра пишет лог, она жива

## 1.0.32-fork.9

- Компиляция наблюдателя фокуса вынесена в кэш: раньше поднималась при
  каждом старте приложения и мешала запуску

## 1.0.32-fork.8

- Вкладка «Сессия»: кнопка-тумблер «Запустить/Остановить» — итоги
  фиксируются, повторный запуск начинает новую сессию

## 1.0.32-fork.7

- Новая вкладка «Сессия»: таймер, весь лут с момента запуска, локации со
  средним временем забега; прежняя вкладка с текущей картой переименована
  в «Локация»

## 1.0.32-fork.6

- Без запущенной игры оверлей спрятан: поверх рабочего стола и чужих окон
  он только мешал

## 1.0.32-fork.5

- Оверлей привязан к окну игры: уходит, когда фокус в другом приложении,
  и возвращается с игрой

## 1.0.32-fork.4

- Установка обновления по кнопке — тихая, с автоматическим перезапуском:
  без мастера установщика

## 1.0.32-fork.3

- Плашку «+N ФЕ» можно переставлять кнопкой из настроек (⚙ → Плашки
  поверх игры → «Переставить…»), не только хоткеем

## 1.0.32-fork.2

- Плашка «+N ФЕ» показывается на мониторе, где идёт игра; перестановка
  мышью (Ctrl+Alt+D)

## 1.0.32-fork.1

- Приложение обновляется с этого репозитория автоматически
- Автопоиск игры: путь Steam берётся из реестра Windows — игра находится,
  даже если Steam установлен вне Program Files
- Цены сообщества из одной пробивки больше не применяются — они
  завышали оценку добычи
- Предметы без названия в справочнике не показываются нигде: забеги,
  цены, стратегии, CSV

## 1.0.32-fork.11

- Загрузка обновлений больше не зависит от системного прокси: локальные
  VPN-клиенты пропускали лёгкую проверку, но рвали скачивание установщика
  с GitHub (504). Теперь трафик обновлений идёт напрямую

## 1.0.32-fork.12

- Вкладка «Сессия», локации: ровные колонки названия, времени и итога;
  длинные названия переносятся на новую строку (перенос отключается
  галкой в настройках)
- Настройки: галки стали переключателями, кнопки — в тёмном стиле
  приложения вместо системных

## 1.0.32-fork.13

- Отзыв лота с биржи в новом протоколе игры (XchgRecall2) учитывается:
  повторное выставление отозванного предмета больше не считается дважды
  в «Выставлено на сумму» и коэффициенте реализации
