# Горн — форк

Форк [Горна](https://github.com/lanqvist/gorn-tli) — трекера Torchlight: Infinite.
Автор оригинала — [lanqvist](https://github.com/lanqvist), лицензия MIT.
Описание проекта, документация и принципы работы — в оригинальном репозитории.

## Отличия от оригинала

- **Автопоиск игры**: путь установки Steam берётся из реестра Windows — находится
  Steam, установленный вне `Program Files` (раньше игра не находилась вообще).
- **Цены сообщества**: агрегат из одной пробивки с одного устройства не
  применяется — завышал оценку добычи.
- **«Пробить цену»**: предметы без названия в справочнике не показываются.
- **Всплывающий доход «+N ФЕ»**: показывается на мониторе, где игра;
  перестановка — ⚙ → Плашки поверх игры → «Переставить…» (или `Ctrl+Alt+D`):
  рамка тащится мышью, «Готово ✓» фиксирует.
- **Вкладка «Сессия»**: таймер и весь лут с момента нажатия «Запустить»,
  локации со средним временем и забегами внутри; прежняя вкладка «Сессия»
  (одна текущая карта) переименована в «Локация».

## Версии и обновление

Версия вида `1.0.32-fork.1`: база — официальная версия, суффикс — номер
сборки фиксов. Приложение обновляется с релизов этого репозитория, релизы
собирает [GitHub Actions](.github/workflows/autobuild.yml): сливает новые
версии автора с фиксами, гоняет тесты, публикует.
